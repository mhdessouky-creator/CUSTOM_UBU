# General-purpose agents

This directory contains a curated set of cross-project agents adapted from [github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/agents). Domain-, application-, and language/runtime-specific agents were intentionally excluded.

Included roles: implementation planning, claim verification, mentoring, critical thinking, devil's advocacy, quality assurance, safe codebase cleanup, and pull request comment handling.
